# Описание набора тестовых сценариев

Документ содержит тестовые сценарии для функционального тестирования интерфейса `Subscribe.ru` по варианту `95033`.

Сценарии сформированы на основе use case-диаграммы и чек-листа тестового покрытия.

## Общие допущения

- тестирование проводится для публичного сайта `https://subscribe.ru/`
- пользователь не авторизован, если явно не сказано обратное
- браузеры выполнения: `Google Chrome` и `Mozilla Firefox`
- взаимодействие с элементами интерфейса выполняется через XPath-локаторы

## TS-01. Просмотр главной страницы

### Связанный прецедент

`UC-01. Просмотреть главную страницу`

### Цель

Проверить, что главная страница `Subscribe.ru` доступна гостю и содержит основные публичные разделы интерфейса.

### Предусловия

- пользователь не авторизован
- открыт браузер

### Шаги

1. Перейти по адресу `https://subscribe.ru/`.
2. Дождаться загрузки главного контентного блока страницы.
3. Найти заголовок `Отборные выпуски рассылок`.
4. Проверить наличие ссылок `Выпуски`, `Группы`, `Подборки`.

### Ожидаемый результат

- главная страница успешно загружается
- виден заголовок `Отборные выпуски рассылок`
- основные разделы навигации доступны пользователю

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldDisplayHomePageNavigation`

## TS-02. Переход в каталог групп

### Связанный прецедент

`UC-03. Открыть каталог групп`

### Цель

Проверить переход из публичной навигации на страницу каталога групп.

### Предусловия

- открыта главная страница сайта
- пользователь не авторизован

### Шаги

1. На главной странице найти ссылку `Группы`.
2. Нажать на ссылку `Группы`.
3. Дождаться загрузки страницы каталога.
4. Проверить, что текущий URL содержит путь `/group/`.
5. Проверить наличие карточек групп на странице.

### Ожидаемый результат

- открывается каталог групп
- URL соответствует ожидаемому разделу
- каталог содержит доступные для просмотра группы

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldNavigateToGroupsCatalog`

## TS-03. Начало регистрации

### Связанный прецедент

`UC-06. Начать регистрацию`

### Цель

Проверить, что гость сайта может начать регистрационный поток из публичного интерфейса.

### Предусловия

- открыта главная страница сайта
- пользователь не авторизован

### Шаги

1. Открыть главную страницу сайта.
2. Найти доступную пользователю ссылку `Регистрация`.
3. Нажать на ссылку `Регистрация`.
4. Дождаться перехода в регистрационный поток.
5. Проверить, что пользователь перенаправлен на путь регистрации или видит регистрационный интерфейс.

### Ожидаемый результат

- регистрационный поток запускается успешно
- пользователь попадает в интерфейс регистрации без необходимости предварительного входа

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldOpenRegistrationPage`

## TS-04. Инициирование подписки на рассылку

### Связанные прецеденты

- `UC-08. Инициировать подписку`
- `UC-09. Подтвердить доступ к подписке через авторизацию/регистрацию`

### Цель

Проверить, что попытка подписки для неавторизованного пользователя переводит его в поток авторизации или регистрации.

### Предусловия

- открыта главная страница сайта
- пользователь не авторизован

### Шаги

1. Открыть главную страницу сайта.
2. Найти первую доступную кнопку `Подписаться`.
3. Нажать кнопку `Подписаться`.
4. Дождаться старта потока подписки.
5. Проверить, что пользователь попадает на маршрут подписки или видит форму авторизации/регистрации.

### Ожидаемый результат

- пользователь не завершает подписку напрямую
- сайт требует дальнейшую авторизацию или регистрацию
- поток подписки запускается корректно

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldOpenAuthorizationPopupWhenSubscriptionStarts`

## TS-05. Открытие карточки группы

### Связанный прецедент

`UC-05. Открыть карточку группы`

### Цель

Проверить, что из каталога групп можно перейти в карточку конкретной группы.

### Предусловия

- открыт каталог групп

### Шаги

1. На странице каталога групп выбрать первую доступную карточку.
2. Нажать на название группы.
3. Дождаться открытия страницы группы.
4. Проверить наличие заголовка группы.

### Ожидаемый результат

- карточка группы открывается без ошибок
- пользователь видит название и основную информацию о группе

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldOpenGroupCard`

## TS-06. Открытие карточки выпуска

### Связанный прецедент

`UC-04. Открыть карточку выпуска`

### Цель

Проверить, что пользователь может открыть отдельный выпуск рассылки из публичного каталога.

### Предусловия

- открыта главная страница сайта с публичными выпусками

### Шаги

1. Открыть главную страницу сайта.
2. Найти ссылку на доступный выпуск в блоке `Отборные выпуски рассылок`.
3. Нажать на ссылку выпуска.
4. Дождаться открытия страницы материала.
5. Проверить, что URL содержит путь `/digest/`.
6. Проверить наличие содержимого материала.

### Ожидаемый результат

- страница выпуска открывается успешно
- пользователь может ознакомиться с содержимым материала

### Автоматизация

- Selenium WebDriver
- XPath-локаторы
- автотест: `shouldOpenDigestCard`
