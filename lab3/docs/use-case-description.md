# Прецеденты использования Subscribe.ru

Документ описывает прецеденты использования сайта `Subscribe.ru` для варианта `95033` и задаёт основу для тестового покрытия лабораторной работы №3.

## Границы системы

Тестируемая система: публичный веб-интерфейс `https://subscribe.ru/`.

В рамках лабораторной рассматриваются пользовательские сценарии, доступные через браузер:

- просмотр публичных разделов сайта
- переход по каталогам и карточкам контента
- запуск регистрации
- запуск сценария подписки

Сценарии внутреннего администрирования, оплаты и работы почтовых серверов в объём данной лабораторной не входят.

## Акторы

### Гость

Неавторизованный посетитель сайта, который:

- открывает главную страницу
- изучает выпуски и группы
- пытается зарегистрироваться
- пытается подписаться на рассылку

### Авторизованный пользователь

Пользователь с учётной записью, который дополнительно может:

- просматривать свои подписки
- управлять списком подписок

Для лабораторной основной фокус сделан на сценариях гостя, потому что они доступны без тестовых учётных данных и хорошо подходят для стабильной Selenium-автоматизации.

## Обоснование выбранного покрытия

Для автоматизации выбраны прецеденты, которые одновременно:

- доступны без тестового аккаунта
- относятся к ключевой функциональности сайта как сервиса рассылок
- позволяют проверить динамический интерфейс с XPath-локаторами
- воспроизводимы в Chrome и Firefox

В текущий набор автоматических тестов входят `UC-01`, `UC-02`, `UC-03`, `UC-04`, `UC-05`, `UC-06`, `UC-08` и `UC-09`.
