# CheckList тестового покрытия

Документ фиксирует тестовое покрытие для сайта `Subscribe.ru`, построенное на основе выделенных прецедентов использования.

Дата актуализации структуры сайта: `18 апреля 2026 года`.

## Область покрытия

В чек-лист включены:

- публичная навигация сайта
- каталог групп и переходы по нему
- запуск регистрационного потока
- запуск потока подписки
- базовые переходы к контенту

В чек-лист не включены:

- сценарии администрирования
- сценарии рассылки писем на внешнюю почту
- сценарии, требующие заранее подготовленного пользовательского аккаунта

## Минимальный обязательный набор для защиты

Если на защите нужно показать только основное покрытие, достаточно пройтись по следующим пунктам:

- `CL-01` - `CL-05`
- `CL-06` - `CL-12`
- `CL-13` - `CL-19`

Этот набор демонстрирует:

- наличие use case-анализа
- связь чек-листа с прецедентами
- автоматизацию ключевых сценариев сайта
- работу Selenium в двух браузерах
